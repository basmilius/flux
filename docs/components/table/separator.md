# Table separator

The table separator is a full-width striped band that splits a table into two runs of rows, for example a set of pinned rows and the rest.

::: render
render=../../code/components/table/separator/preview.vue
:::

::: tip
This component is best used within a [Table](./index). For dynamic data, render it from the [Data table](../data-table)'s `#group` slot.
:::
