# Repeater

The repeater renders a repeating group of form fields: another address, another line item, another phone number. It owns adding, removing and reordering the rows, while the fields inside a row stay yours through the default slot. Validation is not part of it; that stays with [Field](./field/) per field.

::: render
render=../../code/components/form/repeater/preview.vue
:::

::: info
Rows are keyed on the identity of the row object, not on its position, so an input keeps its state when rows move. The key is generated by the repeater and kept outside the model, which means your rows need no id of their own. Keep the same object when you edit a row (`row.street = '...'`) rather than replacing it with a copy.
:::

::: tip
Removing a row that still holds information asks for confirmation first; an empty row is removed right away. Focus is carried along: adding a row moves it into that row's first field, removing one moves it to the remove action that took its place, or to the add action when the last row is gone.
:::
