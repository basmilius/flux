# Flux for React

Use the [installation guide](./installation/manual) to set up `@flux-ui/react`, or browse the [component examples](/react/components/).

The React docs use the same navigation and layout as the original Flux documentation. Examples render native React components. Prop tables are generated from the current React implementation, including event callbacks and render props.

The port is under review. See [port status](/react/status) for verified checks and remaining work.
